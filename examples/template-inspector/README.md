# Template Inspector (`examples/template-inspector`)

This example demonstrates how to inspect the exact prompt template preface generated by LiteRT-LM's internal template renderer prior to generation.

## How It Works

1. Constructs a `litertlm.Client` with model and library paths.
2. Formats messages into a conversation structure.
3. Invokes `client.RenderPreface(messages)` to extract and print the raw formatted preface string with system prompt and chat tokens.

## Usage

```bash
go run . -model /path/to/model.litertlm -system "You are a coding assistant." -prompt "Write hello world in Go"
```

With automatic library and model provisioning:
```bash
go run . -get-lib v0.16.0 -get-model litert-community/gemma3-1b-it-int4
```
