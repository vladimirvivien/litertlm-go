    Getting Started with litertlm-go¶

    Prefer a guided walkthrough?

    Follow Your First Local LLM App in 5 Minutes for a step-by-step tutorial with capability inspection and benchmarks, or jump straight to the Examples Gallery to browse all 48 runnable CLI programs.

    litertlm-go supports two setup workflows: 1. Fully Programmatic Setup (Recommended): Automatically downloads and caches both the native C libraries and the model artifact in Go without manual setup steps. 2. Manual Provisioning: Manually download the .litertlm model file and native shared libraries, specifying their paths via environment variables or options.

    1. Prerequisites¶

    1. Go 1.26 or newer.
    2. Install the package: 
      go get github.com/vladimirvivien/litertlm-go@latest

    2. Method 1: Fully Programmatic Setup (Recommended)¶

    In this workflow, Go automatically fetches the platform prebuilt libraries (litertlm.FetchLib) and downloads the .litertlm model from Hugging Face (litertlm.FetchModel):

    Go Program (main.go)¶

    package main

import (
    "context"
    "fmt"
    "log"
    "runtime"

    "github.com/vladimirvivien/litertlm-go/pkg/litertlm"
)

func main() {
    ctx := context.Background()

    // 1. Automatically fetch and cache native LiteRT-LM shared libraries
    libDir, err := litertlm.FetchLib(ctx, runtime.GOOS, runtime.GOARCH, "v0.19.1")
    if err != nil {
        log.Fatalf("FetchLib failed: %v", err)
    }

    // 2. Automatically download and cache the model from Hugging Face
    modelPath, err := litertlm.FetchModel(ctx, "litert-community/gemma3-1b-it-int4")
    if err != nil {
        log.Fatalf("FetchModel failed: %v", err)
    }

    // 3. Initialize the client using the staged library and model
    client, err := litertlm.New(ctx,
        litertlm.WithLib(libDir),
        litertlm.WithModel(modelPath),
    )
    if err != nil {
        log.Fatalf("Client initialization failed: %v", err)
    }
    defer client.Close()

    // 4. Generate text
    text, err := client.Generate(ctx, "Write a haiku about the sea.")
    if err != nil {
        log.Fatalf("Generation failed: %v", err)
    }
    fmt.Println(text)
}

    Running the Program¶

    go run main.go

    3. Method 2: Manual Model & Library Provisioning¶

    If you already have a model file and native shared libraries on disk:

    Step 1: Obtain the Model File¶

    Download a .litertlm model from Hugging Face's LiteRT Community (e.g., gemma3-1b-it-int4.litertlm or gemma-4-E2B-it.litertlm).

    Step 2: Obtain the Shared Libraries¶

    Download the C-API release archive (litert_lm_c_api-1.0.0.zip) or macOS framework archive from LiteRT-LM Releases:

    mkdir -p ~/include/litertlm/lib
curl -LO https://github.com/google-ai-edge/LiteRT-LM/releases/download/v0.19.1/litert_lm_c_api-1.0.0.zip
unzip litert_lm_c_api-1.0.0.zip -d /tmp/litert_lm_c_api
cp /tmp/litert_lm_c_api/lib/linux_x86_64/liblitert-lm.so ~/include/litertlm/lib/

    mkdir -p ~/include/litertlm/lib
curl -LO https://github.com/google-ai-edge/LiteRT-LM/releases/download/v0.19.1/litert_lm_c_api-1.0.0.zip
unzip litert_lm_c_api-1.0.0.zip -d /tmp/litert_lm_c_api
cp /tmp/litert_lm_c_api/lib/macos_arm64/liblitert-lm.dylib ~/include/litertlm/lib/

    $Env:LITERTLM_LIB = "$Env:USERPROFILE\include\litertlm\lib"
New-Item -ItemType Directory -Path $Env:LITERTLM_LIB -Force | Out-Null
Invoke-WebRequest -Uri https://github.com/google-ai-edge/LiteRT-LM/releases/download/v0.19.1/litert_lm_c_api-1.0.0.zip -OutFile litert_lm_c_api.zip
Expand-Archive -Path litert_lm_c_api.zip -DestinationPath .\litert_lm_c_api -Force
Copy-Item .\litert_lm_c_api\lib\windows_x86_64\litert-lm.dll $Env:LITERTLM_LIB\

    Step 3: Go Program (main.go)¶

    package main

import (
    "context"
    "fmt"
    "os"

    "github.com/vladimirvivien/litertlm-go/pkg/litertlm"
)

func main() {
    ctx := context.Background()

    client, err := litertlm.New(ctx,
        litertlm.WithLib(os.Getenv("LITERTLM_LIB")),
        litertlm.WithModel(os.Getenv("LITERTLM_MODEL")),
    )
    if err != nil {
        fmt.Printf("Initialization failed: %v\n", err)
        os.Exit(1)
    }
    defer client.Close()

    text, err := client.Generate(ctx, "Write a haiku about the sea.")
    if err != nil {
        fmt.Printf("Generation failed: %v\n", err)
        os.Exit(1)
    }
    fmt.Println(text)
}

    Step 4: Run with Environment Variables¶

    LITERTLM_LIB=~/include/litertlm/lib \
LITERTLM_MODEL=~/models/gemma3-1b-it-int4.litertlm \
    go run main.go

    $Env:LITERTLM_LIB = "$Env:USERPROFILE\include\litertlm\lib"
$Env:LITERTLM_MODEL = "$Env:USERPROFILE\models\gemma3-1b-it-int4.litertlm"
go run main.go

    4. Expected Output¶

    Both methods produce text completions directly from the model:

    Blue whispers rise and fall,
Waves crash and secrets hold low,
Ocean breathes its peace now.

    5. Inspecting Model Capabilities & Runtime Version¶

    Before initializing a full inference engine, inspect a .litertlm artifact with litertlm.InspectModel to discover supported input modalities, thinking support, function calling, speculative decoding support, and default sampler settings without allocating KV caches or weights. You can also query the loaded runtime version with litertlm.APIVersion():

    if err := litertlm.Load(os.Getenv("LITERTLM_LIB"), "cpu", ""); err != nil {
    log.Fatal(err)
}
maj, min, pat, err := litertlm.APIVersion()
if err != nil {
    log.Fatal(err)
}
caps, err := litertlm.InspectModel(os.Getenv("LITERTLM_MODEL"))
if err != nil {
    log.Fatal(err)
}
fmt.Printf("C API %d.%d.%d | vision=%v audio=%v thinking=%v tools=%v spec=%v\n",
    maj, min, pat,
    caps.SupportsVision(), caps.SupportsAudio(),
    caps.SupportsThinking, caps.SupportsFunctionCalling, caps.SupportsSpeculativeDecoding,
)

    See examples/capabilities/ for a runnable inspector program.
